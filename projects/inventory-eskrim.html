Sistem Informasi Inventory Es Krim

Aplikasi web berbasis PHP dan MySQL untuk mengelola stok dan inventaris produk es krim. Sistem ini memudahkan pengelolaan data produk, pencatatan stok masuk dan keluar, serta menghasilkan laporan inventaris secara otomatis. Dilengkapi dengan fitur CRUD lengkap dan tampilan dashboard yang informatif.

PHP MySQL Bootstrap HTML CSS
📁 Kategori: Sistem Informasi 🗄️ Database: MySQL 👩‍💻 Role: Full Stack Developer 🖥️ Platform: Localhost (XAMPP)
