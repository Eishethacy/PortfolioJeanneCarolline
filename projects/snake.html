🎮 Game

Snake (Ular)

Game ular klasik yang dimainkan di browser. Kendalikan ular menggunakan tombol panah di keyboard untuk memakan makanan (food) yang muncul secara acak di layar. Setiap kali memakan makanan, tubuh ular bertambah panjang. Game berakhir jika ular menabrak dinding atau tubuhnya sendiri!

HTML CSS JavaScript Canvas API
🔗 Live Demo: eishethacy.github.io/Game-Ular 📁 Kategori: Browser Game 👩‍💻 Role: Solo Developer
