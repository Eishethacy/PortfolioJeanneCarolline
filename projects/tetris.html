Tetris

Game Tetris klasik berbasis web yang dapat dimainkan langsung di browser. Blok (tetromino) turun otomatis dari atas, pemain harus mengaturnya agar membentuk baris penuh yang akan hilang dan menambah skor. Semakin tinggi skor, semakin cepat blok jatuh!

HTML CSS JavaScript Canvas API
