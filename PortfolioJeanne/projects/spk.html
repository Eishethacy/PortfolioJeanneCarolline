Sistem Pendukung Keputusan

Aplikasi Sistem Pendukung Keputusan (SPK) berbasis website yang dikembangkan sebagai penelitian/skripsi di PT Clar Fortune Properti. Sistem ini menggunakan kombinasi metode AHP (Analytical Hierarchy Process) dan TOPSIS (Technique for Order Preference by Similarity to Ideal Solution) untuk membantu strategi pemasaran pada proyek properti. Digunakan dalam lingkup kurang lebih 70 kerjasama proyek properti.

PHP MySQL Bootstrap AHP TOPSIS
🏢 Klien: PT Clar Fortune Properti (Fortune Hom3) 📁 Kategori: Penelitian / Skripsi 🗄️ Database: MySQL 🧮 Metode: AHP + TOPSIS 📅 Tahun: 2025–2026 🎯 Scope: ±70 proyek properti
